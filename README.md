# SecretarioMudoIoT-Paradigmas
Proyecto Secretario Mudo IoT - Paradigmas de Programación UNA
**Profesor:** Eddier López  

## Descripción del Proyecto
El Secretario Mudo IoT es una solución tecnológica compacta diseñada para espacios de trabajo o estudio. Utiliza un microcontrolador ESP32 para actuar como un asistente ambiental y de enfoque. Reúne en un solo punto físico información clave (hora sincronizada por Wi-Fi, temperatura y humedad) y herramientas de gestión del tiempo (temporizador Pomodoro interactivo con iluminación ambiental adaptativa).

**Objetivo:** Reducir las distracciones digitales cotidianas, evitando que el usuario revise su teléfono móvil o abra nuevas pestañas en el navegador.

## Tecnologías y Componentes
- **Microcontrolador:** ESP32
- **Sensores:** DHT11 (Temp/Humedad), Fotorresistencia LDR (Luz)
- **Actuadores:** Pantalla LCD 16x2 I2C, LED RGB, Buzzer
- **Entradas:** Potenciómetro (Selección de tiempo)
- **Software:** Arduino IDE, C++ (Paradigmas: POO y Máquina de Estados)
